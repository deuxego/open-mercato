# @open-mercato/core 🧠

Build production-grade business modules on top of the Open Mercato platform.

`@open-mercato/core` is the business engine: auth, directory, customer_accounts, integrations, data_sync, dashboards, notifications, and module infrastructure.

## Why this package ✨

- 🧩 Ready-made domain modules for real business apps
- 🔐 Built-in ACL, tenancy, and secure-by-default conventions
- ⚡ Command-based architecture for robust writes and undo support
- 🛠 Extensible module system with API/page auto-discovery

## Install

```bash
yarn add @open-mercato/core
```
